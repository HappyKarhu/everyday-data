# Project 001: Turning Off the Tap While Brushing Teeth

## Research question

What is the environmental impact of turning off the tap while brushing your teeth for one year?

## Purpose

This folder contains the research materials, assumptions, calculations, and charts that support the related Everyday Data article. It is kept in the repository so that readers who want to inspect or reproduce the analysis can do so.

## Contents

- `assumptions.md` explains the selected values and why they were chosen.
- `data/assumptions.csv` stores the source-based input values used by the analysis.
- `data/dataset.csv` is generated by the analysis script.
- `scripts/analysis.py` calculates water use for the included brushing scenarios.
- `scripts/charts.py` creates the chart from the generated dataset.
- `output/water_per_brush.png` is the generated chart.
- `research/sources.xlsx` contains the project source list.

Reusable notes for the cited sources are in the repository's `library/` folder. Source IDs in the assumptions file correspond to those notes.

## Reproduce the analysis

From this project folder, run:

```powershell
python scripts/analysis.py
python scripts/charts.py
```

The scripts require Python with Pandas and Matplotlib installed. Running them refreshes `data/dataset.csv` and `output/water_per_brush.png`.

## Scope

The calculations model water use while the tap is running for each listed brushing duration. Any assumption about how long water runs for wetting or rinsing should be documented separately before using this project to estimate savings from turning off the tap.
